# AIMEMI — вторая память

AIMEMI — это бот в Telegram. Ему можно отправить заметку, ссылку, фото, документ или голосовое сообщение. Он сам выбирает категорию и потом находит запись обычными словами.

Отдельный сайт, регистрация и оплата не нужны. Умный поиск через платный ИИ тоже не подключён: бот ищет по словам, типу записи и понятным периодам вроде «вчера» или «на прошлой неделе».

## Что умеет бот

- здоровается и показывает меню;
- сохраняет текст, ссылки, фото, документы и голосовые;
- раскладывает записи по категориям: Работа, Личное, Идеи, Обучение и Покупки;
- даёт редактировать текст, добавить в избранное и удалить;
- ищет только среди записей этого человека;
- хранит записи в файле базы, поэтому обычный перезапуск их не стирает.

Напоминания, расшифровка голоса и поиск «по смыслу» оставлены на потом: для них понадобились бы отдельные сервисы.

## Из чего состоит проект

- `index.js` — запускает бота.
- `src/bot.js` — получает сообщения из Telegram и отвечает.
- `src/telegram.js` — связь с Telegram без дополнительных библиотек.
- `src/handlers.js` — решает, что делать с кнопкой или текстом.
- `src/messages.js` — тексты и кнопки.
- `src/categories.js` — правила, по которым выбирается категория.
- `src/search.js` — разбирает обычный запрос.
- `src/memory.js` — сохраняет, ищет, меняет и удаляет записи.
- `src/db.js` — база SQLite в файле `data/aimemi.sqlite`.
- `src/health.js` — короткая служебная проверка для площадки, без личных данных.
- `.gitignore` — список того, что нельзя отправлять в интернет. Там есть `.env`, любые env-файлы и база.
- `Dockerfile` — сборка образа для Timeweb Cloud App Platform.
- `.dockerignore` — что не попадает в образ (в том числе `.env` и база).
- `tests` — автоматические проверки сценариев.

Секретный токен в этих файлах не хранится.

Имя переменной токена: **`TELEGRAM_BOT_TOKEN`**.

## Как завести бота в BotFather

1. Открой Telegram и найди `@BotFather`.
2. Нажми «Начать» и отправь `/newbot`.
3. Имя бота: `AIMEMI`.
4. Короткое имя латиницей, оно должно заканчиваться на `bot`. Например, `aimemi_memory_bot`, если это имя свободно.
5. BotFather пришлёт токен. Это пароль бота. Его нельзя отправлять друзьям, вставлять в чат и сохранять в GitHub.
6. По желанию отправь BotFather `/setdescription` и напиши коротко, что AIMEMI хранит заметки и помогает их найти.
7. По желанию поставь аватар через `/setuserpic`: спокойная картинка в фиолетовых и лавандовых тонах.
8. Список команд в меню Telegram бот обновляет сам при запуске. Отдельно через BotFather его настраивать не нужно.

## Как продолжить через GitHub Desktop

Публиковать проект нужно только когда ты сама этого хочешь.

1. Установи GitHub Desktop с сайта https://desktop.github.com и войди в свой аккаунт.
2. В меню File выбери Add local repository.
3. Укажи папку этого проекта. Если программа предложит создать репозиторий, согласись.
4. Внизу напиши комментарий, например: «Первая версия AIMEMI».
5. Нажми Commit to main.
6. Когда решишь выложить код, нажми Publish repository и оставь репозиторий частным.
7. Перед публикацией в списке файлов GitHub Desktop не должно быть `.env`, `.env.example` и `data/aimemi.sqlite`. Токен добавляй только в переменные Timeweb: `TELEGRAM_BOT_TOKEN`.

## Как запустить на Timeweb Cloud (Dockerfile)

Бот работает через **polling** (сам спрашивает Telegram о новых сообщениях). Webhook не нужен.

1. Открой https://timeweb.cloud и войди в панель.
2. Перейди в App Platform и нажми «Создать».
3. Подключи GitHub и выбери репозиторий AIMEMI. Ветку оставь `main`.
4. Выбери развёртывание через **Dockerfile**. Файл `Dockerfile` лежит в корне проекта — путь к нему обычно оставляют как есть.
5. Открой расширенные настройки.
6. В переменных нажми «Добавить». Имя переменной точно такое: `TELEGRAM_BOT_TOKEN`. Значение — токен из BotFather. Не включай «Сохранить как глобальную». В код и в Dockerfile токен не вписывай.
7. По желанию добавь `APP_TIMEZONE` со значением `Europe/Moscow`. Без неё бот тоже использует московское время.
8. Путь проверки состояния можно указать `/health` (бот отвечает `ok`, если платформа передала `PORT`). Если поле оставить пустым — тоже нормально: бот всё равно ходит в Telegram через polling.
9. Создай приложение и дождись, когда статус станет запущенным.
10. Открой своего бота в Telegram и нажми «Начать».

С одним и тем же токеном должна работать только одна копия бота (не держи одновременно локальный запуск и Timeweb).

## Как проверить бота в Telegram

- Нажми «Начать». Должны появиться приветствие и кнопка «🚀 Начать», а затем меню из пяти кнопок.
- Пришли обычную фразу про работу, учёбу или покупку. Бот должен ответить, что запись сохранена, и назвать категорию.
- Пришли ссылку, фото, документ и голосовое. Каждая запись должна сохраниться.
- Пришли стикер. Бот должен вежливо подсказать, какие форматы он умеет принимать.
- Нажми «Найти» и напиши слово из своей заметки. Бот должен показать именно её.
- Открой запись, добавь в избранное и удали.
- Попроси другого человека написать тому же боту. Он не должен видеть твои записи.
- В панели Timeweb нажми «Перезагрузить» и выбери перезапуск контейнера. После запуска записи должны остаться на месте.

## Важное про сохранность данных

Записи хранятся в файле SQLite: `data/aimemi.sqlite` (внутри контейнера).

- **Обычный перезапуск контейнера** файл обычно не стирает — записи могут остаться.
- **Новая сборка / повторный деплой** на Timeweb App Platform поднимает окружение заново. Постоянный диск к приложению не подключается, поэтому **база с записями пользователей при повторном развёртывании может исчезнуть**.
- В образ и в GitHub файл базы не попадает (это настроено в `.gitignore` и `.dockerignore`).

Для **постоянного** хранения позже понадобится внешнее хранилище (например, отдельная база или S3) и доработка проекта. В первой версии платные сервисы и внешнюю базу не подключаем.

## Если бот молчит

- Проверь, что приложение на Timeweb запущено.
- Проверь имя переменной: `TELEGRAM_BOT_TOKEN`, без пробелов и кавычек.
- Убедись, что деплой идёт через Dockerfile из корня репозитория.
- Открой вкладку «Логи приложения». Там может быть написано, что токен не принят. Самого токена в логах быть не должно. Если токен не принят, заново скопируй его у BotFather и впиши в переменную.
- В Telegram отправь `/start`.
- Если бот запущен и локально, и на Timeweb сразу — останови одну копию: иначе Telegram может отвечать конфликтом.
